# Contributing to Systema Auxilium

Thanks for taking the time to look at this project! Systema Auxilium is a personal
project that's grown to a point where outside input and collaboration would genuinely
help — so any contribution, big or small, is appreciated.

---

## Ways to Contribute

- **Bug reports** — If something breaks or behaves unexpectedly, please open an issue
  with as much detail as you can (OS, Python version, what you ran, what happened).

- **Feature suggestions** — Have an idea that fits the project? Open an issue and
  describe it. No suggestion is too small.

- **Pull requests** — Improvements to code, documentation, or structure are all welcome.
  Please open an issue first if the change is significant, so we can discuss it before
  you invest time writing it.

- **General feedback** — Even if you just want to share thoughts on how the project
  could be better, that's welcome too.

---

## Guidelines

- Keep changes focused. One fix or feature per pull request makes review much easier.
- Write clear commit messages that describe *what* changed and *why*.
- If your change touches system-level behavior, please test it carefully before
  submitting — this software interacts with OS-level operations.
- Be respectful. This is a personal project maintained by one person. Constructive,
  patient communication goes a long way.
